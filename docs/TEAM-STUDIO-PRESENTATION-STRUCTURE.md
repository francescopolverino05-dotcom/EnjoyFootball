# Team Studio presentation structure

How the LiveTag.pro **Team Studio** opposition reports are built (Perugia, Benevento, Avellino).  
Videos stay on Desktop — this note is the template only.

**Author on all three:** Arcieri Marco — Match Analyst Pro FIGC & UEFA B  
**Tool:** LiveTag.pro (watermark bottom-left on every slide and clip)  
**Length:** about 8–10 minutes  
**Picture:** wide tactical cam (full pitch), not broadcast zoom

---

## The skeleton (always this order)

Every report is the same machine. Only the bullets, formations, and clip count change.

1. **Title card** — club crest left, `TEAM STUDIO` right, club-colour gradient, analyst credit under the LiveTag logo.
2. **Lineup board** — isometric pitch, shirt numbers 1–11, names stacked per role (depth chart), formations top-right, `Allenatore …` bottom-right.
3. **Chapter card: FASE OFFENSIVA** — crest + 4–5 bullets (the offensive agenda).
4. **Offensive clips** — one clip (or a short series) per bullet, in the same order as the card.
5. **Chapter card: FASE DIFENSIVA** — crest + 3–4 bullets.
6. **Defensive clips** — same rule: bullets, then matching clips.
7. **Chapter card: PALLE INATTIVE OFFENSIVE**
8. **Attacking set-piece clips** — kick-off → wide free kick → central free kick → corner.
9. **Chapter card: PALLE INATTIVE DIFENSIVE**
10. **Defending set-piece clips** — same types, fewer examples.

Chapter cards are 2–4 seconds. Then the clips start.

---

## How each clip is labelled

Top-left overlay, three lines:

| Line | What it is | Example |
|------|------------|---------|
| 1 (team colour) | Phase / event | `Costruzione`, `Pressione`, `Corner` |
| 2 (white) | Detail — formation, principle, or pattern | `4-1/2-1-2`, `Veloce e verticale` |
| 3 (white) | Index inside that series | `1 di 3`, `2 di 4` |

If there is only one example, line 3 is omitted (`Costruzione lunga`, `Punizione centrale`).

Clips are **examples of a principle**, not a full-match edit. Typical series length is 1–4 clips.

---

## Step-by-step: build one report

### 1. Title

- Left: opponent crest (large)
- Right: **TEAM STUDIO**
- Background: that club’s colours (green/white Avellino, yellow/red Benevento, red Perugia)
- Footer: LiveTag.pro + `ARCIERI MARCO - MATCH ANALYST PRO FIGC & UEFA B`

### 2. Lineup board

- Draw the **main** shape on the pitch (e.g. 4-3-1-2 or 3-5-2)
- List **alternate** shapes top-right (Avellino also 4-3-2-1; Benevento also 4-3-3)
- Per position: number in a circle + every player used there
- GK circle in a different colour
- Coach name on the pitch

### 3. Offensive chapter card, then clips

Write 4–5 bullets. Then film them **in that order**.

Shared offensive ladder (names flex per team):

1. **Costruzione** — first build-up shape (`4-1/2-1-2`, `3-1/4-1-1`, `4-1/2-3 o 3-1/4-2`). 2–3 clips. Extra line if the shape changes inside the series (`Interni in ampiezza`, `Palla in movimento`).
2. **Width / full-back–midfielder relation** — `Rotazione Terzino-Interno`, `Interni in ampiezza`, `Quinti di spinta`, `Costruzione lunga`.
3. **Progression** — `Sviluppo` (sometimes `Play sotto linea`).
4. **How they attack the box** — direct + second ball, and/or combinations (`Attacco alla linea`, trequartista–striker, `Ricerca Attaccante`).
5. **Offensive transition** — fast/vertical, or consolidate vs restart (`Transizione consolidamento o ripartenza`).

### 4. Defensive chapter card, then clips

Usually 3–4 bullets:

1. **First press** — high / man-oriented (`Pressione`, `Prima pressione a uomo` / `alta`). More clips here than anywhere else (up to 4).
2. **Rest defence / block** — mid-block shape (`Difesa a metà campo`, `Blocco medio 5-3-2`) or a note on the back line (`Linea difensiva`, markings, depth).
3. **Defensive transition** — almost always **riaggressione** (counter-press), 1 clip.

### 5. Attacking set pieces

No bullet list on the chapter card — just the title. Then this sequence:

1. `Calcio d'inizio` (1–2)
2. `Punizione laterale` (1–2)
3. `Punizione centrale` (0–1)
4. `Corner` (2–4; last one can be a named pattern, e.g. `Giocata a 3`)

### 6. Defending set pieces

Same title style (`PALLE INATTIVE DIFENSIVE`). Shorter:

1. `Calcio d'inizio` (1)
2. `Punizione laterale` (1)
3. `Corner` (1–2)

No central free kick in the three samples.

## What is template vs what is unique

**Template (do not change):** title → board → offensive chapter → clips → defensive chapter → clips → attacking set pieces → defending set pieces. Overlay grammar. LiveTag watermark. Analyst footer on graphic slides.

**Unique per opponent:** colours, crest, coach, numbered depth chart, the bullet wording, clip counts, and any extra “fault” clip (Benevento’s `Leggerezza e palla persa`) or named player principle (Giugliano between the lines).
