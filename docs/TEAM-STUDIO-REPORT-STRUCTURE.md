# Team Studio video report — step-by-step structure

Decoded from LiveTag.pro “Team Studio” presentations (Avellino, Benevento; Perugia uses the same template). Author on the samples: **Arcieri Marco — Match Analyst Pro FIGC & UEFA B**. Length is typically **8–10 minutes**. Videos were not added to the repo.

Every report is the same skeleton. Only the club colours, formation, player names, and the wording of each clip label change.

---

## The 10-step template

### 1. Title card — `TEAM STUDIO`

- Club crest left, **TEAM STUDIO** right
- Club-colour background (white/green for Avellino, yellow/red for Benevento)
- Footer: LiveTag.pro + analyst credit

### 2. Formation / depth-chart board

- 3D pitch graphic, numbered position circles
- Names stacked on each spot (starter + rotation)
- Formations listed top-right (e.g. `4-3-1-2` / `4-3-2-1`, or `3-5-2` / `4-3-3`)
- Coach bottom-right: `Allenatore …`

### 3. Section card — `FASE OFFENSIVA`

Crest + title + **bullet agenda** of the attacking themes that follow. This is the roadmap for steps 4–5.

### 4. Offensive clips (wide tactical cam)

Each clip has a top-left overlay:

```text
[Phase name]          ← coloured
[Shape / detail]      ← optional second line
N di M                ← clip index inside that theme
```

Typical order (themes may be skipped or split):

1. **Costruzione** — build-up shape (`4-1/2-1-2`, `3-1/4-1-1`, …), often 2–3 clips
2. Extra build-up notes if needed — e.g. **Costruzione lunga**, **Interni in ampiezza**, **Palla in movimento**
3. **Sviluppo** — progression after the first line
4. Optional: **Attacco diretto e seconda palla** / **Leggerezza e palla persa**
5. **Attacco alla linea** — combinations, width, depth, trequartista–striker link
6. **Transizione** (with the ball) — e.g. *Veloce e verticale*, *Consolidamento*, *Ripartenza*

### 5. Section card — `FASE DIFENSIVA`

Crest + title + bullet agenda of the defending themes.

### 6. Defensive clips

Same overlay style. Typical order:

1. **Pressione** / **Prima pressione** (often *alta* or *a uomo*)
2. **Difesa a metà campo** / **Blocco medio** (with the block shape, e.g. `5-3-2`)
3. Optional: **Linea difensiva** (marking, depth, ball wide)
4. **Transizione — Riaggressione** (counter-press after loss)

### 7. Section card — `PALLE INATTIVE OFFENSIVE`

### 8. Offensive set-piece clips

Always in this order when present:

1. **Calcio d'inizio**
2. **Punizione laterale**
3. **Punizione centrale** (if they have one)
4. **Corner** (sometimes a named variant, e.g. *Giocata a 3*)

### 9. Section card — `PALLE INATTIVE DIFENSIVE`

### 10. Defensive set-piece clips

Same labels, fewer clips:

1. **Calcio d'inizio**
2. **Punizione laterale**
3. **Corner**

No closing card — the last defensive set-piece clip is the end.

---

## What every clip looks like

| On screen | Where | What it is |
| --- | --- | --- |
| Phase title | Top-left, coloured | Theme (`Costruzione`, `Pressione`, `Corner`, …) |
| Detail line | Under the title | Shape or coaching point |
| `N di M` | Under that | Which example in the theme |
| Full-pitch footage | Rest of the frame | Wide tactical cam (often Veo) |
| `LIVETAG.PRO` | Bottom-left | Watermark |

Section cards are **static graphics** (crest + title + bullets). Clips are **match video** with the overlay. No telestration drawing on the samples — just the label and the wide shot.

## How to rebuild one

1. Title card with the opponent crest and **TEAM STUDIO**
2. One formation board (depth chart + coach)
3. Four blocks, each = **section card → labelled clips**:
   - Fase offensiva
   - Fase difensiva
   - Palle inattive offensive
   - Palle inattive difensive
4. 1–4 clips per theme, indexed `N di M`
5. Keep the overlay language in Italian; change only the opponent-specific bullets and shapes
